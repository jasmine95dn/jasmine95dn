## Featured Projects

### [kaping_prompt_zero-shot](https://github.com/jasmine95dn/kaping_prompt_zero-shot) ⭐ 29
Reimplementation of the KAPING framework for zero-shot question answering over knowledge graphs using prompt-based LLMs.

### [SmartPub](https://github.com/jasmine95dn/SmartPub-INLPT-WS2023)
RAG-powered chatbot for querying biomedical literature. Retrieves PubMed abstracts via Pinecone vector search and generates answers using Llama 2 13B. Built with LangChain, Flask, Docker, and automated CI/CD via GitHub Actions.

### [srl-context-emb](https://github.com/jasmine95dn/srl-context-emb)
Research into span-based semantic role labeling models with contextualized embeddings (ELMo, BERT).

### [flask_best_worst_scaling](https://github.com/jasmine95dn/flask_best_worst_scaling)
Web app for Best-Worst Scaling annotation, a ranking method used in NLP data collection.
